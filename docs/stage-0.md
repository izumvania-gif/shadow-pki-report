## Как запустить калибровочный прогон (п. 5)

```bash
python3 tools/ct_pull.py rutoken.ru guardant.ru aktiv-company.ru --months 24 --out out/
```

Зависимостей нет, только стандартная библиотека Python 3. Скрипт обращается исключительно к публичному реестру CT — к хостам доменов он не ходит, DNS-резолвинг в него намеренно не включён.

На выходе по каждому домену: сводка в консоль и JSON в `out/`. В сводке главное — строка «коэффициент завышения без группировки»: во сколько раз отчёт соврал бы, считая записи CT вместо линий сертификатов.

Проверить перед разбором: **точный корневой домен Актив.** В конфигах стоит `aktiv-company.ru`, это предположение.

Для источника с отпечатком публичного ключа:

```bash
python3 tools/ct_pull.py rutoken.ru --source certspotter --token "$CERTSPOTTER_TOKEN"
```

## Что вскрылось на этапе 0

### А. Обязательное поле не отдаётся основным источником

Требования (п. 2.1) считают отпечаток публичного ключа обязательным — на нём стоит правило «один ключ на несвязанных именах». JSON-эндпоинт списка `crt.sh` этого поля **не отдаёт**, как и длины ключа, типа ключа и алгоритма подписи.

Затронуты три правила из одиннадцати: `shared_key_unrelated_names`, `rsa_key_short`, `weak_signature`.

Варианты, выбрать до старта разработки:

| Вариант | Цена | Риск |
|---|---|---|
| Догружать каждый сертификат отдельным запросом и разбирать DER | Заметно дороже по времени и по лимитам: запросов становится столько же, сколько сертификатов | Упирается в лимиты источника на крупном домене |
| Второй источник, отдающий поле сразу (Cert Spotter и аналоги) | Токен и лимиты бесплатного тарифа | Нужно проверить, хватает ли глубины выборки |
| Отложить три правила на следующий шаг | Бесплатно | Теряется правило про общий ключ — одно из самых наглядных на встрече |

**Это влияет на оценку этапа 1**, поэтому решение принимается на этапе 0, а не в первый день хакатона. Скрипт поддерживает оба источника — проверить оба на калибровочных доменах и сравнить полноту.

### Б. Доступность источников из нашей сети не подтверждена

Пункт «подтверждена доступность из нашей сети» остаётся открытым и его нельзя закрывать по умолчанию: в среде, где готовились эти материалы, `crt.sh` оказался закрыт исходящей политикой (`403` на CONNECT). Это не проблема источника, а напоминание, что доступ нужно проверять именно оттуда, откуда пойдут запросы, и до старта.

Проверить: доступность `crt.sh` и выбранного второго источника, фактические лимиты, поведение при их превышении.

### В. Модель трудозатрат без источника не выводится

В `config/rules.yaml` секция `effort_model` намеренно оставлена с пустыми значениями и флагом `render_without_source: false`: без ссылки на отраслевой источник раздел в отчёт не попадает.

Причина в том, что это самая конвертирующая часть отчёта, и экспертная оценка «мы считаем, что внутренних сертификатов в X раз больше» на встрече с ИТ-директором весит заметно меньше ссылки на исследование. Пустые значения лучше выдуманных.

## Что остаётся за продактом

Пункты, которые нельзя закрыть без доступа к внутренним данным и людям:

1. **Договорённость с компанией из базы на сверку находок с её реестром (п. 13).** Единственный незакрытый пункт из трёх критичных по оценке. Собственные домены группы дают эталон и позволяют посчитать полноту и ложные срабатывания — но Актив производит средства защиты информации, и его дисциплина выпуска заведомо выше средней по сегменту. Продуктовая гипотеза «компания не знает своих сертификатов» проверяется только там, где заказчик сверит находки со своим учётом и скажет, что чего-то не знал.
2. **Отбор 10 демонстрационных доменов (п. 7)** — нужен доступ к базе контактов.
3. **Вычитка формулировок (п. 3).** Черновик написан в констатирующем тоне и без обвинительных конструкций, но окончательные тексты — зона продакта.
4. **Юрпроверка (п. 12).** Два узких вопроса: правомерность сбора по публичным реестрам и корректность формы передачи документа компании, с которой отношения уже есть. Вопрос массовой рассылки снят — её не делаем.

## Открытые вопросы

- Отраслевой источник для соотношения внутренних и внешних сертификатов. Без него раздел о трудозатратах не выводится.
- Нужна ли контрольная группа: раз все адресаты — знакомые компании, отклик смещён вверх сам по себе, и «отчёт конвертирует лучше письма» без контрольной группы недоказуемо.
- Какой источник CT берём основным — см. находку А.
- Точный корневой домен Актив.
